# 💰 Sistema Financeiro Família

Sistema de controle financeiro familiar com login, dízimos/primícias e acompanhamento de investimentos.

## Como funciona
- Cada família tem um login próprio (e-mail + senha)
- Quem cria a conta gera um código de convite para os outros membros da família entrarem
- Os dados ficam salvos na nuvem (Supabase) e sincronizam entre os aparelhos da família em tempo real
